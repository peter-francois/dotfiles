# dotfiles

Personal configuration for my development environment: WSL2 (Ubuntu) + Zsh.

## Contents

- `zsh/.zshrc`: Oh My Zsh, plugins (git, gh, ssh-agent, fzf, autosuggestions, syntax-highlighting), zoxide
- `zsh/.p10k.zsh`: Powerlevel10k prompt
- `git/.gitconfig`: git defaults (rebase on pull, SSH commit signing)
- `claude/settings.json`: my Claude Code settings, without the hooks generated by Orca
- `install.sh`: symlinks the files into `~`, merges the Claude settings and installs the Zsh plugins

## Prerequisites

- Zsh and Oh My Zsh
- zoxide, fzf
- Python 3
- MesloLGS NF font set in the terminal

## Install

    git clone git@github.com:peter-francois/dotfiles.git ~/projects/dotfiles
    cd ~/projects/dotfiles && ./install.sh
    exec zsh

Existing files are backed up as `*.backup.<date>` before being replaced.

## Claude Code settings

Orca rewrites `~/.claude/settings.json` at startup and adds its own hooks, so this file is not symlinked. `claude/settings.json` holds my settings, and `install.sh` merges them into the live file.

- **Change or add a setting:** edit `claude/settings.json`, then run `./install.sh`.
- **Remove a permission rule:** remove it from both `claude/settings.json` and `~/.claude/settings.json`. The merge never removes anything.
- **Keep a setting changed from Claude Code or Orca:** copy it into `claude/settings.json`. It is not saved there automatically.
- **Orca hooks:** do not add them to `claude/settings.json`. Orca regenerates them at startup.
